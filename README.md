# 长寿房产直播背景板合集

重庆长寿本地房产抖音直播用的竖屏背景板，**透明洞版式**（中间留空给主播/摄像头，四周放楼盘信息），两套配色方案，均含 HTML 源文件与 1080×1920 导出图。

| 主题 | 配色 | 定位 | 目录 |
|---|---|---|---|
| **翡翠金 · 透明洞版** | 深翡翠绿 `#0d2b1e` + 金 `#d4af37` | 沉稳、夜场感强，适合双盘对比（凤城华府 / 菩提一品） | [`emerald-gold/`](emerald-gold/) |
| **暖米白浅木风** | 暖米白 `#F5F0E6` + 浅木 `#C4A276` | 明亮、日间感，单盘深度讲解（璞缇一品云幕系列） | [`warm-cream-wood/`](warm-cream-wood/) |

## 通用规格

- **画幅**：竖屏 9:16；设计画布 405×720 px；导出 1080×1920 px
- **透明洞**：`body` / `.stage` 背景全透明，中间区域不放背景色，直播时由摄像头画面透出
- **字体**：Noto Serif SC（标题衬线）+ Noto Sans SC（正文），Google Fonts 引入；离线环境自动回退系统字体
- **适配**：`<script>` 内 `fit()` 按 `min(vw/405, vh/720)` 等比缩放，改窗口尺寸不拉伸

## 使用方法

1. **直接当背景图**：把对应目录的 `preview-1080x1920.png` 导入 OBS / 抖音直播伴侣，放在摄像头图层之下。
2. **改文案再导出**：编辑 `index.html` 中的文字 → 浏览器打开 → 截图或无头浏览器导出 1080×1920 PNG。
   无头导出示例（Windows / Edge）：
   ```bash
   msedge.exe --headless --disable-gpu --force-device-scale-factor=2 \
     --window-size=810,1440 --screenshot=out.png "file:///绝对路径/index.html"
   ```
   `--force-device-scale-factor=2` 会把 405×720 渲染成 810×1440；输出 1080×1920 时用 `2.6667`。
3. **安全区**：文字已收进纵向 150–540px 安全带，避开平台顶部头像栏与底部评论区；**正式开播前仍建议用平台预览功能实测一遍**（不同机型 ±20px 差异）。

## 合规要点（长寿房产直播口径）

- 不出现「书包房 / 学区房」，不承诺对口入学；学校信息仅作周边配套陈述
- 不写「保值 / 稳赚 / 洼地 / 租金抵月供 / 零首付」等承诺性表述
- 极限词（最 / 第一 / 唯一 / 顶级 / 封顶）需替换为客观描述
- 不按时长、公里数描述距离；规划配套不承诺落地时间
- 不引导站外（微信 / 电话 / 售楼部），转化统一走平台小风车
- 报价统一按建筑面积；价格与销售政策以当月开发商口径为准，开播前复核
